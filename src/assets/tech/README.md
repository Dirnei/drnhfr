Vendored technology logos for the skills graph and the project pages.
`<title>`, `<desc>`, comments, `width`/`height` and every built-in colour were
removed and `fill="currentColor"` added to the root element, so the page sets
the colour. Nothing else changed. Which technology uses which file is in
`src/data/tech-icons.json`.

Simple Icons (CC0), from simple-icons 16.33.0:
  angular, ansible, arduino, astro, contao, docker, dotnet, espressif,
  githubactions, kubernetes, mongodb, mqtt, nuget,
  openapiinitiative, opentelemetry, php, proxmox, pwa, raspberrypi, react,
  svg, terraform, typescript, typo3, vite, vitest, yaml.

Devicon (MIT), from devicon 2.17.0:
  akka (akka-plain), csharp (csharp-plain), java (java-plain),
  microsoftsqlserver (microsoftsqlserver-plain), visualbasic (visualbasic-plain).
